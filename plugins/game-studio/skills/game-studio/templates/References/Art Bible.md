# Art Bible

Owned by art-director. The law for artist and the yardstick for reviews.

## Palette
Colors come only from `References/palette.json`. Color roles: background, player, enemies, UI, accents.

## Scale
Tile and base sprite size in pixels, output scale (×2, ×3), pixel grid.

## Outline
Outline or not, thickness, color, outer or inner.

## Light and shadow
Light direction, number of shadow steps, dithering or not.

## Animation
FPS by type (idle, walk, attack), frame counts, principles (squash, anticipation).

## UI
Grid, spacing, buttons, icons, states (normal, hover, pressed, disabled).

## Fonts
Which fonts, sizes, license.

## Don'ts
What we never do: gradients, translucency, off-palette colors, etc.
